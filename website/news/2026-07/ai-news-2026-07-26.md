### GitHub Dependabot 引入三天冷却期，延迟版本更新 PR 以提升安全性

<p class="news-entry-meta"><time datetime="2026-07-24">2026-07-24</time></p>

GitHub Dependabot 新增默认三天冷却期，延迟版本更新 PR 的创建，让维护者和安全研究人员有时间在新版本发布后处理潜在问题，避免有漏洞的更新直接进入代码库。对读者：启用此功能可降低依赖更新引入安全风险的概率，建议团队在安全敏感项目中开启。
